## Use When
- Creating new frontend screens
- Improving weak or cluttered layouts
- Building admin panels, dashboards, forms, cards, tables, or modals
- Implementing Laravel Blade, Livewire, Inertia, React, or Filament UI
- Building hospital or clinic software interfaces

---

## Core Standards
- Prefer clean spacing and strong visual hierarchy
- Use consistent padding, border radius, shadows, and typography
- Design mobile-first and ensure responsive behavior
- Prefer reusable components over repeated markup
- Add empty states, loading states, validation states, and success/error feedback
- Avoid crowded screens
- Keep actions visually clear
- Prioritize accessibility basics:
  - labels for inputs
  - visible focus states
  - sufficient contrast
  - semantic structure

---

## Tailwind Guidance
- Use consistent container widths
- Prefer utility composition with clear structure
- Avoid excessive nested divs
- Use grid/flex intentionally
- Keep color usage limited and consistent
- Standardize button, input, badge, and card styles
