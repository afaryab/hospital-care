## Common for All Roles

### Logging In
1. Open the hospital system URL in your browser.
2. Enter your **email** and **password**.
3. If Two-Factor Authentication (2FA) is enabled, enter the 6-digit code from your authenticator app.
4. Click **Login**.

### Logging Out
Click your **name/avatar** in the top-right corner → **Logout**.

### Changing Your Password
Settings → Password → enter current password and new password → Save.

### Patient Number Format
Every patient has a unique **PS Number** in the format:  
`PS / YEAR / MONTH / SEQUENCE` e.g. `PS/2024/03/0001`

### Transaction Number Format
`TR / YEAR / MONTH / DAY / SEQUENCE` e.g. `TR/2024/03/15/0001`

### Counter (Closing) Number Format
`CT / YEAR / MONTH / SEQUENCE` e.g. `CT/2024/03/0001`
